# 31天主线接入说明

内容源是用户提供的《天马行空-31天剧情对话正文-精简重写稿.md》，完整保存在 `31-days.md`；`src/game/script.json` 保留35章的段落，含31天、三个结局与提前失败场景。运行时的 `story.ts` 按段落取场景，`speakers.ts` 标记发言人和叙述焦点。正文中的条件段落作为剧情数据，按实际选择和结果分流。`npm run story:check` 检查内容源一致；修改正文后运行 `npm run story:compile`，并检查 `story.ts` / `speakers.ts` 的段落索引，不应仅重新生成JSON而忽略演出指令。

## 事件与动作

| 阶段 | 事件入口与玩法 |
| --- | --- |
| 1–7 | 信箱、马详情、第一次扔套索、相扑报名/结果、可选配种、修围栏、搭擂台、第一笔还款 |
| 8–14 | 红帐篷演出/劳务、可选测序、报告、湿地/丘陵试跑、二次育种、豆包比赛、第二笔还款 |
| 15–21 | 修堤、林谷三棒演练、K研究、可选编辑、旧规划与老赵往事、完璧展示、样本七号比赛、第三笔还款 |
| 22–28 | 旧缰绳与第七页日记、雪山两种取样、实验室方案、普通或嵌合育种或暂缓、幼马真实外观、完璧掌声练习选择、成年后三匹接力 |
| 29–31 | 候选马讨论、收购抉择、真实杯赛赛果、扣草料后最后还款、逐句结局演出 |

经营动作成功后才扣时间、改变状态并发出剧情事件。演出奖金来自模拟结果；报名、下注有17:00截止检查。读完场景的选择会更新任务牌，跳过育种、编辑、取样中的捕获不会卡住下一日。日记关键页支持在相关地点晚取。

出生使用配种时保存的双亲基因快照和羽翼材料等位基因。成年规则是 `bornDay + 2`：25日准备 → 26日出生 → 28日成年；29日配种的小马32日才成年。实际有羽翼需要携带材料并达到相容度，预算额外消耗18点；物理升力有速度、姿态、体力门槛及额外体力消耗，不保证起飞或获胜。

接力各棒80米，草地/丘陵、湿地/海岸、林谷/雪山。总成绩按三棒真实用时相加；未完成的棒使用45秒加剩余距离罚秒，摔倒不能成为捷径。NPC队伍目前在三棒使用各自代表马的同一身体参数，玩家需要三匹不同成年马。

## 存档与演出

v4存档包含已触发场景、选择、历史、未读对白、马匹档案、亲本快照、器官材料和待结算演出。每读一句就保存，保留该段剧情所属日和章名，因此夜间读档不会把上一日对白误标成新的一天。结局也是可恢复的对白队列。

演出开始先记录马、项目、日和场次，刷新后重建同一种子比赛；完成后清票据再发钱，重复回调不结算。正式赛事用日期和参赛名单生成种子，读档后未结算的已报名/下注赛事可重新入场。每天结算标记防止重复派奖、公开战绩和保险退款。

透明角色图集提供待机、手势、欢呼、低头四个姿势。`StoryStage` 根据焦点角色和文字切姿态，配合入场缓动、步态与呼吸；实际马使用已有物理木偶。场景道具、马戏背景采用透明图集，地形高度与赛场绘制共享同一个函数。

## 验证范围

单元测试覆盖动作原子性、读档、重复结算、出生与成年、普通/羽翼表现分支、编辑边界、三匹接力、还款日期、宽限限制、结局和31天流程。稳定性检查1000匹随机马。经营模拟使用真实赛果与演出收益，捕获操作简化为50%成功，不计赶路、不预演下注；用于检查可行经营路径。

浏览器人工自动化覆盖对白与角色图层、演出中刷新、编辑、雪山拾羽毛、丘陵试跑、三棒报名/结算、收购和杯赛/结局。浏览器临时存档用于快速定位日期，完整31天推进另由状态流程测试验证。
