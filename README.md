# 天马行空

当前版本只保留可自由探索的像素世界与场景框架。

- 牧场、马蹄镇、赛马场、研究所、擂台、红帐篷与野原，以及湿地、丘陵、海岸、林谷、雪山的地图入口。
- WASD或方向键移动，Shift跑步，点地面移动，E互动，M打开大地图，Esc打开菜单。
- 建筑、摆设、环境人物、马群、动物、水面动画、动态日照和四首原创区域配乐。
- 场景入口展示基础场景框架。基因、身体、赛跑与相扑物理以及对应渲染模块作为底层基础保留。
- 行走推进世界时钟，点时钟可休息一小时或进入下一天。日期不限制探索。

浏览器本地存档使用独立的 `tianma.world.v1`，只保存世界位置、日期、时钟和累计步行距离。启动时自动删除旧版 `tianma.save` 系列存档，保留当前世界存档和音乐设置。存档不上传服务器，不跨浏览器或设备同步。

## 本地运行

需要Node 22或更新（推荐24）。

```bash
npm ci
npm run dev            # http://localhost:5173
npm test               # 地图、时钟、存档、配乐、基因与物理
npm run sim:stability  # 1000匹随机马的物理稳定性检查
npm run build          # 类型检查并打包到dist/
npm run music:render   # 重生成配乐，需ffmpeg
```

| 目录 | 内容 |
| --- | --- |
| `src/genome` / `src/body` | 遗传、表达、身体与代谢预算 |
| `src/sim` | 固定步长物理、地貌、赛跑与相扑基础 |
| `src/game` | 世界状态、时钟与本地存档 |
| `src/render` | 马匹与像素场景绘制 |
| `src/world` | 大世界、地图、光照、移动与环境动画 |
| `src/audio` | 区域配乐与播放控制 |
| `src/ui` | 像素木框、世界界面和场景渲染基础 |
