# 天马行空

物理驱动的育马游戏。回到外婆留下的牧场，从两匹马和300元开始：观察身体、育种、套马、选项目参赛或演出，在31天内还清抵押款。

## 可玩的流程

- 自由走动的大世界：牧场、马蹄镇、赛场、研究所、红帐篷，以及湿地、丘陵、海岸、林谷、雪山。WASD移动，Shift跑步，点地面寻路，E互动，M打开地图。
- 31天对白使用[润色正文](docs/story/31-days.md)。场景随实际交互、选择与赛果触发；任务木牌和地图指路，信箱收信、日报预告天气，日记和“一路走来”可回看。没读完的对白会随存档恢复。
- 老赵、米娅、小白、K、马董、阿桃采用透明PNG角色图集，随对白入场、做手势、欢呼或低头。家、赛场、帐篷、研究所、海岸、林谷和雪山有不同布景；剧情中显示玩家实际的马，幼马大小和可用羽翼随育种结果变化。
- 套索每日三根，野马会躲，套中后拉绳控制张力。马厩最多12匹，待产小马占位置。配种次日出生，出生两天后成年。
- 前期按外形和试跑判断。第10天测序所开放，首次100元、以后200元，次晨出报告。第18天可编辑一个位点的一条链，每匹每天一次，首次免费、以后1500元。
- 第8天起马戏团可选择成年马和拉车、越障、平衡台节目，每天最多两场，按真实距离、摔倒和倾斜支付演出收入。修围栏、搭擂台、搭帐篷、修堤各有一次劳务收入。
- 六种地貌有不同摩擦或阻力；丘陵有实际起伏碰撞面，林谷有低枝，雪山地滑。第16天可用现有马及借来的马做接力演练。
- 第23天雪山取样可选择套马或拾羽毛，满马厩仍能拾材料；第25天可尝试背部嵌合育种。羽翼材料可遗传，但能否长出可用羽翼、发挥作用要看相容度和身体，主线允许普通马参加。
- 奇数日平地赛、偶数日相扑；7日铁墩相扑擂台、14日豆包赛跑擂台、21日样本七号擂台。28日是三匹不同成年马参加的三棒六地貌接力，31日是八匹马400米天马杯。下注只按公开战绩给赔率，可买保险。
- 四笔还款在7/14/21/31日夜里，分别2000/8000/20000/30000元，先扣草料。前三笔合计只有一次三日宽限、加付20%，最后一笔不延期。30日可以接受收购；31日根据真实杯赛成绩和还款得到三个结局之一。守住牧场后从32日继续经营。

大世界沿用主分支的动态日照与四首原创区域配乐。首次操作解锁音乐，设置中可开关、调音量，赛事和切到后台时淡出。

游戏沿用动作时钟：每天06:00开始，17:00开赛，19:00后散场，午夜休息。对白、看马和浏览面板不花时间；配种60分钟、试跑30分钟、测序20分钟、报名与下注10分钟、演出90分钟、编辑60分钟、嵌合育种120分钟，走40格花15分钟。点钟表可休息或等到开赛。

存档在浏览器本地，兼容v2/v3并写入v4。演出中刷新会从同一种子恢复；已报名/下注的正式比赛中刷新可重新入场，费用和结算不会重复。普通马码兼容TM2，携带羽翼材料使用TM3。

## 本地运行

需要Node 22或更新（推荐24）。

```bash
npm ci
npm run dev            # http://localhost:5173
npm run story:check    # 验证剧情JSON与润色正文一致
npm test               # 基因、身体、物理、31天剧情、经营与存档
npm run sim:stability  # 1000匹随机马各跑10秒，检查有限值和成绩分布
npm run sim:economy    # 两个31天经营存档，真实比赛/接力/演出及夜间结算
npm run build          # 类型检查并打包到dist/
npm run music:render   # 重生成配乐，需ffmpeg
```

## 实现与验证

[接入说明](docs/story/implementation.md)记录事件映射、存档和演出方式。角色/道具图集及其布局说明在[素材目录](public/assets/story/README.md)。

当前是首版可玩实现：背部羽翼是首个可遗传器官，尚未扩展全部嵌合槽；角色演出采用四种姿势结合位移动画。马戏项目按风力、地貌和稳定性判定，平衡台道具还没有独立的平台碰撞体。经济模拟简化捕获成功率、不计赶路，不能替代玩家难度测试。

| 目录 | 内容 |
| --- | --- |
| `src/genome` / `src/body` | 遗传、突变、表达、身体与代谢预算 |
| `src/sim` | 固定1/60秒物理步长的马、地貌、赛跑、相扑 |
| `src/game` | 动作时钟、赛事、经济、存档、剧情、经营玩法 |
| `src/render` | 马匹、像素布景、透明图集绘制 |
| `src/world` | 大世界、地图、光照、寻路、套索 |
| `src/audio` | 区域配乐、交互解锁、音量与淡入淡出 |
| `src/ui` | 像素木框界面、对白演出、马戏/赛事舞台 |
