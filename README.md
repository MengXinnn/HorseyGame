# 天马行空 · Neigh-tural Selection

一个物理驱动的育马沙盒网页游戏：一代一代培育你的马，给它装上翅膀、龟壳或轮子，在山水之间的赛道上，让物理决定谁是黑马。

设计书：https://claude.ai/artifact/DaNSqNw7RHMibuj1Xo4JcN

## 现在能玩什么（原型 M0）

M0 验证的是整条因果链：**基因 → 身体 → 物理 → 成绩**。

- **马厩**：开局四匹马（流星、磐石和两匹野马）。可以套野马、两匹马配种生小马（会遗传，偶尔突变）、用马码导入朋友的马。
- **测序**：没测序只能看外表和跑出来的成绩，测序后才能看到 16 个位点的两条链。
- **试跑场**：选中的马单独跑 10 秒，看它能跑多远。
- **平地赛**：你的马对阵 7 匹野马，200 米。
- 代谢预算、嵌合槽已经在面板上，部件在 M1 开放。存档在浏览器本地。

## 本地运行

需要 Node 22 或更新（推荐 24，CI 用的是 24）。

```bash
npm install
npm run dev            # 打开 http://localhost:5173
npm test               # 单元测试（基因、马码、身体、物理确定性、存档）
npm run sim:stability  # 1000 匹随机马各跑 10 秒，检查模拟稳定
npm run build          # 类型检查 + 打包到 dist/
```

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `src/genome` | 16 个位点、表达、繁殖与突变、马码、代谢预算和嵌合槽 |
| `src/body` | 基因表现值 → 身体参数（尺寸、质量、扭矩、步频、平衡） |
| `src/sim` | planck.js 物理马、比赛（固定 1/60 秒步长 + 种子随机数，结果可复现） |
| `src/render` | 山水剪影场景和马匹绘制（Canvas 2D，渲染层独立，之后可换 PixiJS） |
| `src/game` | 存档、马厩操作、野马对手 |
| `src/ui` | 界面和舞台 |
