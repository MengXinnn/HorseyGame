# 天马行空

一个物理驱动的育马沙盒网页游戏：一代一代培育你的马，在山水之间的大世界里套马、配种、比赛、还债，让物理决定谁是黑马。

设计书：https://claude.ai/artifact/DaNSqNw7RHMibuj1Xo4JcN

## 现在能玩什么（M1 第一周）

你继承了外婆的牧场和六万块债。马董每七天来收一笔，第一笔两千，第七天夜里。

- **大世界**：一条河把地图分成南北两半。北边是赛马场（看台、赌马、报名处）、马蹄镇（喷泉广场、马市、茶馆、杂货、铁匠铺、民居、土地庙）、赵家擂台和镇外林子后面的研究所（测序）；南边是牧场和野原。自由走动（WASD 或点地面，Shift 跑，E 互动），左上角小地图，按 M 看整张地图。
- **时间**：一天从清晨 6 点到午夜，但时间不会自己走——做一件事才花一段时间：配种 1 小时、试跑和牵回套中的马各半小时、测序、卖马、导入马码各 20 分钟、报名、下注、扔一次套索各 10 分钟，走路按路程算，每走 40 格花 15 分钟（从家走到镇上大约半小时）。逛、看马、翻马厩、和老赵聊天都不花时间。点钟表可以歇一小时，或者直接等到傍晚开赛；做不完的事不让做，只有赶路会把人拖过午夜（累倒在路边）。
- **昼夜**：白天云影飘过，早晚斜斜的光柱，夜里窗户、灯笼、路灯、篝火一盏盏亮起来，水边的树和人有倒影。
- **套马**：野原上每天一批野马，会跑会躲。点马扔套索（每天 3 根），套中后按住拉绳，把张力保持在绿区里。
- **配种和测序**：马厩里选两匹马配种，第二天早上小马出生，两天长大。镇上测序 200 块，第二天早上看到基因。
- **赛事**：单日平地赛（8 匹马 400 米），双日相扑（推出圈或掀翻），第七天老赵的铁墩摆擂台。报名 50 块，傍晚 5 点开赛。
- **下注**：庄家只看公开战绩，没比过赛的新马赔率最高（黑马）。下注上限随名望增长，可以买保险。
- **夜晚结算**：饲料钱、出生、测序结果、还债，一页账本。
- 马市卖马、告示牌导入朋友的马码、老赵的对白。存档在浏览器本地。

## 本地运行

需要 Node 22 或更新（推荐 24，CI 用的是 24）。

```bash
npm install
npm run dev            # 打开 http://localhost:5173
npm test               # 单元测试（基因、身体、物理、相扑、经济、存档）
npm run sim:stability  # 1000 匹随机马各跑 10 秒，检查模拟稳定
npm run build          # 类型检查 + 打包到 dist/
```

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `src/genome` | 16 个位点、表达、繁殖与突变、马码、代谢预算和嵌合槽 |
| `src/body` | 基因表现值 → 身体参数（尺寸、质量、扭矩、步频、平衡） |
| `src/sim` | planck.js 物理马、平地赛、相扑（固定 1/60 秒步长 + 种子随机数，结果可复现） |
| `src/render` | 赛场的像素背景（抖动的天空、远山剪影条）、看台人群和马匹绘制（Canvas 2D，渲染层独立，之后可换 PixiJS） |
| `src/game` | 日程和经济、赔率、存档、马厩和赛事规则、老赵对白 |
| `src/world` | 大世界：地图布局（`tiles.ts`）、地面和人物（`sprites.ts`）、摆设（`props.ts`）、3/4 俯视的房子（`buildingArt.ts`）、光照（`lighting.ts`）、小地图（`minimap.ts`）、大世界里的马、套马 |
| `src/ui` | 星露谷式像素界面（`pixelui.ts` 生成木框边框）、HUD 和面板、像素化的赛场和相扑台 |
