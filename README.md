# 天马行空

一个物理驱动的育马沙盒网页游戏：一代一代培育你的马，在山水之间的大世界里套马、配种、比赛、还债，让物理决定谁是黑马。

设计书：https://claude.ai/artifact/DaNSqNw7RHMibuj1Xo4JcN

## 现在能玩什么（M2 第一阶段：四周赛季 + 剧情）

你在城里接到老赵的电话：外婆走了。回到马蹄镇，外婆留下牧场和两匹马，马董拿着六万块的借据找上门，四个礼拜分四笔还。

- **剧情**：开场回忆、老赵接站、外婆的信。左上角任务木牌一次挂一个任务，地图箭头指路。门口信箱收信，第 8 天起每天一份《马蹄镇日报》。外婆的日记散在各处，道具栏里翻看。剧本：https://claude.ai/code/artifact/237504cd-0b89-441a-b40d-5003fa39f7eb
- **基因慢慢出现**：第一周只有比赛、配种、下注。测序所第 10 天开门，拿到第一份测序结果后，马的详情里才多出基因栏。
- **赛季日历**：单日平地赛、双日相扑，每周第七天擂台（老赵的铁墩、米娅的豆包、K 博士的样本七号），第 28 天天马杯（马董的完璧，看台满座，胆小的马会发呆）。奖金逐周上涨。
- **日报天气**：雨天地滑、大风顶风、赏月节低重力、冰面，物理参数真的变。
- **还债和结局**：还不上马董宽限一次（三天，多两成），再还不上牧场变乐园（吉祥物结局）；四笔还清后看天马杯定「天马行空」或「守住了」，之后接着养马。第 27 天夜里马董会出价收购。
- **大世界**：牧场、马蹄镇、赛马场、野原连成一片（WASD 或点地面，Shift 跑，E 互动）。套马、配种、测序、马市、马码、下注和保险照旧。

## 本地运行

需要 Node 22 或更新（推荐 24，CI 用的是 24）。

```bash
npm install
npm run dev            # 打开 http://localhost:5173
npm test               # 单元测试（基因、身体、物理、相扑、经济、存档）
npm run sim:stability  # 1000 匹随机马各跑 10 秒，检查模拟稳定
npm run sim:economy    # 模拟玩家过 28 天，看四笔债还不还得上（调奖金用）
npm run build          # 类型检查 + 打包到 dist/
```

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `src/genome` | 16 个位点、表达、繁殖与突变、马码、代谢预算和嵌合槽 |
| `src/body` | 基因表现值 → 身体参数（尺寸、质量、扭矩、步频、平衡） |
| `src/sim` | planck.js 物理马、平地赛、相扑（固定 1/60 秒步长 + 种子随机数，结果可复现） |
| `src/render` | 山水剪影场景和马匹绘制（Canvas 2D，渲染层独立，之后可换 PixiJS） |
| `src/game` | 日程和经济、赛季日历和天气、赔率、存档、马厩和赛事规则、剧情（任务、对白、信、日记、结局） |
| `src/world` | 大世界：俯视像素地图（`tiles.ts`）、代码画的像素美术（`sprites.ts`）、大世界里的马、套马 |
| `src/ui` | 星露谷式像素界面（`pixelui.ts` 生成木框边框）、HUD 和面板、像素化的赛场和相扑台 |
