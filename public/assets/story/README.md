# 剧情透明素材

按用户授权使用图像生成制作，2026-10-13。均为有真实Alpha通道的RGBA PNG，人物/道具周围透明。运行时关闭平滑插值，按像素画显示。

- `characters.png`：1024×1536，4列×6行。行顺序：老赵、米娅、小白、K先生、马董、阿桃；列顺序：待机、手势、欢呼、低头。
- `props.png`：1254×1254，4列×4行。图像生成后的实际留白并非严格等分，裁切列界 `[0,340,640,950,1254]`、行界 `[0,350,650,940,1254]`，映射在 `storyAssets.ts`。
- 道具顺序：帐篷、舞台、草料、信箱；马车、越障架、平衡台、观众；桥、山岩、码头、林谷枯木；雪山羽毛、马厩、实验台、奖杯。

运行时以 `import.meta.env.BASE_URL` 定位文件，可部署到子路径。图片未就绪时角色使用代码像素画回退；这些PNG是图集，不是帧率驱动的完整逐帧动画，演出位移由代码控制。
